# Photo Viewer Advanced

Photo Viewer Advanced is a free, open-source, offline image viewer for Windows and Linux. Designed to be simple and easy to use, it supports a wide variety of image formats, animated images, and camera RAW files.

Beyond viewing images, it includes basic editing tools, image conversion, folder browsing, and customizable viewing options.

## Features

- **Wide Format Support:** Open common, modern, professional, and RAW image formats.
- **Animated Images:** Play GIF, animated WebP, APNG, and animated AVIF with playback controls.
- **Image Editing:** Crop, rotate, and flip images.
- **Image Conversion:** Export images to a variety of supported formats.
- **Folder Browsing:** Navigate image collections using thumbnails or keyboard shortcuts.
- **Zoom & Fullscreen:** Inspect images at full resolution with zooming, panning, and fullscreen viewing.
- **Slideshows:** Browse images automatically with adjustable intervals.
- **Customization:** Adjust appearance, zoom behavior, and animation settings.
- **Offline Operation:** No accounts, cloud services, or internet connection required for normal use.
- **Check for Updates:** Use the toolbar button to download and install the latest release from GitHub.

## Supported Formats

| Category | Formats |
|---|---|
| Standard | JPEG, PNG, BMP, TIFF |
| Modern | WebP, AVIF, HEIC, JPEG XL |
| Animated | GIF, WebP, APNG, AVIF |
| Professional | PSD, SVG, OpenEXR, HDR |
| Additional | ICO, DDS, TGA, QOI, JPEG 2000 |
| Camera RAW | DNG, CR2, CR3, NEF, ARW, RAF, ORF, RW2 |

Some formats have limitations, such as still-preview-only support or camera-dependent RAW compatibility.
